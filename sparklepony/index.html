Sparkle Pony

High-performance email contact extractor for Microsoft Outlook PST files. Native Rust parsing, parallel extraction, and direct reads of ZIP archives without expanding them.

What you get

Section titled “What you get”

Native PST parsing

Rust-native PST parsing through the outlook-pst crate. No Outlook, no COM automation, no Python dependency chain — just a binary that reads the format directly.

ZIP archives, read in place

Stored (uncompressed) PST entries inside a ZIP are read straight through the archive at byte offsets. Zero extra disk space, zero decompression step.

Split PSTs, stitched

A mailbox exported across .001, .002, *.001.pst, or archive.pst.001 parts is reassembled across archives into one logical PST automatically.

Parallel by default

Mailboxes are extracted across a Rayon worker pool under live CPU and memory limits. The resource manager watches the machine and backs off before the box gets into trouble.

Filtering that matches reality

TLD validation against the IANA registry, RFC 5322 syntax checks, and a configurable blacklist that splits role accounts and bulk-mail domains out of the list.
