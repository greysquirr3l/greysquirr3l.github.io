CLI reference

Global flags

Section titled “Global flags”
Flag Default Description
--debug off Enable debug logging. Accepted at the root or on any subcommand.
--help — Print help for the root command or a subcommand.
--version — Print the short version string.

Command tree

Section titled “Command tree”
Command Purpose
extract Extract contacts from PST files and archives. The default.
validate emails RFC 5321/5322 syntax validation.
validate mx DNS-over-HTTPS MX domain validation.
exclude Split a contacts CSV by blacklist exclusion rules.
version Print detailed build/version information.

extract is the default when flags are passed at the root, so these are equivalent:

extract

Section titled “extract”

Extract contacts from PST files, ZIP archives, and multi-part PSTs.

Flag Short Default Description
--input <PATH> -i — Path to a PST file, a ZIP archive, or a folder containing them
--output <PATH> -o contacts.csv Output CSV file path
--workers <N> -w 0 (auto) Maximum worker threads
--cpu <PCT> 70.0 Maximum CPU usage percentage (0–100)
--memory <PCT> 70.0 Maximum memory usage percentage (0–100)
--min-free-memory <GB> 2 Minimum free memory in GB before the run backs off
--ignore-space-check off Skip the disk-space check
--temp-dir <PATH> system temp Directory for tempfiles when decompressing deflated ZIP entries
--safe off Safe mode — more conservative resource usage
--disable-tld-filter off Skip TLD validation against the IANA registry
--extract-attachments off Extract attachments while processing PSTs
--chunk-size <MB> 32 Chunk size for processing, in MB
--max-username-length <N> 20 Maximum local-part length for email filtering
--skip-senders off Do not extract sender addresses
--skip-recipients off Do not extract recipient addresses (To, CC, BCC)
--no-progress off Disable the progress bar
--exclude-ambiguous off Also exclude ambiguous shared mailboxes (hello@, info@, sales@)
--blacklist <PATH> auto Blacklist file to apply

Input

Section titled “Input”

--input accepts a single PST, a ZIP archive, a folder to traverse, or any mixture of those. Split multi-part PSTs are reassembled automatically — point at any one part and the siblings are found next to it.

Output

Section titled “Output”

The CSV has three columns:

Column Description
email Email address, lowercased and trimmed
name Display name, when the message carried one
source The PST, archive, or work item the contact came from

Examples

Section titled “Examples”

validate emails

Section titled “validate emails”

Validate addresses against RFC 5321/5322 syntax rules and split the input into compliant and malformed files.

Flag Short Default Description
--input <PATH> -i - (stdin) Input CSV file
--output-valid <PATH> -o output/ark_contacts_valid.csv Output for RFC-compliant addresses
--output-invalid <PATH> -x output/ark_contacts_invalid.csv Output for malformed addresses
--quiet -q off Suppress the per-address INVALID: lines
--no-progress off Disable the progress bar

The header row is preserved in both outputs, and missing output directories are created automatically.

validate mx

Section titled “validate mx”

Check whether each domain can receive mail, using DNS-over-HTTPS MX lookups.

Flag Short Default Description
--input <PATH> -i output/ark_contacts_valid.csv Input CSV with emails in the first column
--output-valid <PATH> -o output/ark_contacts_mx_valid.csv Output for rows with valid mail-receiving domains
--output-invalid <PATH> -x output/ark_contacts_mx_invalid.csv Output for rows with invalid or dead domains
--output-errors <PATH> none Separate CSV for rows whose domain lookup errored
--timeout <SECS> 8 DoH request timeout, in seconds
--concurrency <N> 6 Maximum concurrent DoH queries
--delay-ms <MS> 10 Delay after each new query per worker
--no-throttle off Disable rate limiting
--retries <N> 2 Max retries per query — primary provider, then fallback
--no-a-fallback off Disable the RFC 5321 fallback to A records when no MX is published
--stats-only off Print stats without writing output files
--quiet -q off Suppress progress printing
--no-progress off Disable the progress bar

The progress bar tracks unique domains resolved, not raw rows — only the first row for a domain triggers a lookup.

exclude

Section titled “exclude”

Split a contacts CSV by the blacklist exclusion rules.

Flag Short Default Description
--input <PATH> -i - (stdin) Input CSV file
--output-kept <PATH> -o output/contacts_kept.csv Output for addresses that pass the rules
--output-excluded <PATH> -x output/contacts_excluded.csv Output for addresses removed by the rules
--blacklist <PATH> -b auto Blacklist configuration file
--explain -e off Print the address and the rule that excluded each one
--include-ambiguous off Also exclude shared mailboxes whose display name may be a person

The blacklist path resolves the same way extract resolves it, so the two commands never disagree about which addresses are excluded.

version

Section titled “version”

Print detailed build-time metadata derived from git by build.rs: commit hash, branch, commit date, rustc version, and target triple.

Exit codes

Section titled “Exit codes”
Code Meaning
0 Success
1 A runtime error — bad input, unwritable output, network failure
