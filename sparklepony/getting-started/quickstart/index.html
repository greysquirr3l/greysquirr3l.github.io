Quick start

The one-liner

Section titled “The one-liner”

extract is the default subcommand, so the flags work at the root too:

The output file has three columns:

Column Description
email The address itself
name Display name, when the message carried one
source The PST (or archive) the address came from

Accepting anything

Section titled “Accepting anything”

You do not need to sort your input by type. The extractor walks a path and recognises each shape it meets:

Supported inputs:

  • A single .pst file
  • A folder of .pst files, traversed in parallel
  • A .zip archive containing PSTs
  • Multi-part split PSTs — .001/.002, *.001.pst, archive.pst.001 — are reassembled into one logical PST across archives

See ZIP and split PSTs for the details of how archives are read.

Controlling the machine it runs on

Section titled “Controlling the machine it runs on”

Extraction is resource-managed by default: CPU and memory ceilings, a minimum free-memory floor, and a worker count that adapts to the host.
