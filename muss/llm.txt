# muss

> Approachable Rust crates for Microsoft 365. The first crate, muss-teams,
> is a framework-neutral Teams SDK: one dependency, one facade, ordinary
> async functions. Where Microsoft's documentation leaves a question open,
> the SDK records the reading it chose, and marks what no live tenant has
> confirmed.

A Cargo workspace of Rust crates for building Microsoft 365 integrations.
`muss-teams` is the product: a framework-neutral Teams SDK covering
authenticated bot activities, interactive Adaptive Cards, proactive
messages, Graph notifications, dialogs, message extensions and sign-in, all
behind one facade. `muss-core` holds the M365-generic primitives.
`muss-teams-cli` is an optional companion binary. Sign-in and the Graph
clients sit behind feature flags and are off by default.
