CLI commands used

Entirely never re-implements Entire. It finds the entire binary, reads its JSON output, and shells out for anything that changes state. Every call goes through one runner (src/services/cli/runner.ts), so timeouts, output capture and failure handling are decided once. See Architecture.

The list below is section 1 of docs/coverage.md, grouped by area. A test scans src/ and fails if a call to a known command has no row there, so the list tracks the code. Derived against Entire CLI 0.12.2.

Read means the call does not change Entire, your repository or your login. Changes means it does. Commands you start from the editor that change something ask first; the Commands page says which confirm. The hook bridge runs on its own when editor agent events occur.

Flags are read at run time

Section titled “Flags are read at run time”

The extension does not keep a list of CLI flags. Before it builds an invocation that has options, it asks the installed CLI, with entire agent-help <command>. Each part of a command path is passed as its own word, for example agent-help repo mirror add. The extension parses the flags and descriptions out of the text and builds the call from what it finds. Examples:

  • Agent reinstall appears only when agent add --help describes a reinstall flag.
  • Import picks the agent from the CLI’s own help.
  • Control Plane calls take their flag names from agent-help.

A few commands are runnable but missing from agent-help, such as experimental ones. For those the runner reads the command’s own --help. The entire mcp check does this.

If the CLI is missing or too old to describe a command, the feature says so and does nothing else. The CI job “Check the Entire CLI contract” (npm run check:cli) installs the pinned CLI version and checks that agent-help still lists the flags the extension passes. See Testing.

Privacy of the call record

Section titled “Privacy of the call record”

The runner keeps a record of each call for the output channel and Doctor: Show the Last Entire CLI Output. Options on the call decide what that record may hold. Transcripts, search queries, comment bodies and plugin arguments are kept out. See Privacy and redaction.
