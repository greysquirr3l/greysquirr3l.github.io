Commands

Entirely contributes 63 commands. All of them share the category Entirely, so the Command Palette shows each as Entirely: <title>. The table below was generated from contributes.commands and contributes.menus in package.json, then each description was checked against src/.

Reading the tables:

  • Where lists the places beyond the palette. view title is the toolbar of a view, inline is the icon on a tree row, context is a right-click menu, editor is the editor’s context menu or title bar.
  • Changes says whether the command changes anything on Entire, in the repository or in your settings. Read means it only reads. Confirms means a modal prompt names what will change and nothing runs until you agree. Asks for input, no confirmation means you pick or type something and the command then runs without a further prompt. See Privacy and redaction for what the extension keeps out of its logs.
  • Hidden commands are registered with commandPalette: false. They exist for menus, tree rows and links, and never show in the palette.

Several commands that have a menu entry are also in the palette, for example Entirely: Create Repository. The ones that are not are marked hidden.

Approve runs right after you pick the change, and comment runs right after you type the text, so neither confirms. The timeout is entirely.trailActionTimeout.

The agent skill

Section titled “The agent skill”
Palette title Id Where Changes What it does
Entirely: Install the Agent Skill in This Repository entirely.installAgentSkill palette Confirms before it replaces a file Writes .github/skills/entire/SKILL.md into the repository that is open: one file that tells an agent working there what Entire already knows, and which commands only read.

The skill names the commands and the two flags that shape what an agent reads — --json and --compact. Every other flag comes from entire agent-help <command>, so the text stays true as the CLI changes. It does not list the commands that change something either: entire agent-help marks which ones those are, and the skill points at that list. A file that is already there is the person’s, and it is replaced only after they are asked, and only after the question names it without claiming where it came from. A link in its place, or a folder that leads out of the repository, is refused. Nothing else in the repository is touched.
