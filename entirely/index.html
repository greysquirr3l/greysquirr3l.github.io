Entirely

See Entire's agent sessions, checkpoints and trails from inside VS Code. The CLI does the work; Entirely puts it in the editor.
Get startedView on GitHub

Entirely is an unofficial, community extension. It is not affiliated with or endorsed by Entire.

Entire is a Git forge built for agent-human collaboration. It records what coding agents did as sessions, freezes them into checkpoints, and publishes that history so a team can see what every agent did and why. The Entire CLI does the work. Entirely is the editor-side surface for it.

What you get

Section titled “What you get”

A status bar that knows

Shows whether the workspace is tracked by Entire and whether an agent session is live right now. See Status bar.

Sessions and checkpoints

Every session Entire tracks for the repository, with the transcript in a read-only editor and each checkpoint opening straight into the native diff. See Sessions and checkpoints.

Trails and review

Approve, comment on, merge and check out Entire trails. Merge, check out, link and unlink ask first, and each merge names what it merges. Approve and comment run once you pick a change or type the text. See Trails and review.

Why this line

Select a line and see which agent edit introduced it, and why. File blame marks every line as attributed, recorded but not synced, or unattributed. See Blame and why this line.

Search and activity

Search past agent work, commits and code, and read recent activity, a generated dispatch and a recap. See Search and Activity, dispatch and recap.

Setup and control plane

Manage agent integrations, plugins and the MCP server, and browse or change projects, repositories and organisations. Changes name the target and the login. See Control plane.

The extension never re-implements Entire. It discovers the installed CLI, reads its JSON output, and shells out for anything that changes state. If the CLI is missing, it shows a clear message with a link to the install instructions. When something is wrong, Diagnose problems explains the report and the output channel.
