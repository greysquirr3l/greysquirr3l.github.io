Releases

Neon Echo is released from the sparklepony repository alongside the CLI. Both live in one Cargo workspace, so a release tag covers both.

Current version

Section titled “Current version”

0.1.0 — bundle identifier com.greysquirr3l.neon-echo.

Where to get it

Section titled “Where to get it”

Release bundles are attached to the GitHub release for the corresponding tag. Tags look like neon-echo-v0.1.0 — they are namespaced separately from the CLI’s own tags, so a CLI release never triggers an app release.

Build matrix

Section titled “Build matrix”

The release workflow builds three targets:

Target Runner Artifacts
aarch64-apple-darwin macos-14 .dmg, .app
x86_64-pc-windows-msvc windows-latest NSIS .exe, .msi
x86_64-unknown-linux-gnu ubuntu-22.04 .AppImage, .deb

Looking for the CLI?

The sparklepony binary has its own releases and its own documentation. See the sparklepony site for CLI installation and the full command reference.

Platform notes

Section titled “Platform notes”

macOS

Section titled “macOS”

The release matrix builds Apple Silicon (aarch64-apple-darwin) only. The .dmg contains a standard .app bundle. The app is ad-hoc signed — see Installation for the Gatekeeper step.

Windows

Section titled “Windows”

Two installer formats are produced: an NSIS installer (-setup.exe) and an MSI. Both are unsigned unless WINDOWS_CERTIFICATE is configured as a repository secret, so SmartScreen will warn on first launch until the user allows it.

Linux

Section titled “Linux”

An .AppImage and a .deb are produced on Ubuntu 22.04. The .AppImage needs the execute bit set before it will run.

Building a release from source

Section titled “Building a release from source”

Output lands in src-tauri/target/release/bundle/.

Version numbers

Section titled “Version numbers”

The app version is declared in three places that must agree:

  • neon_echo/package.json
  • neon_echo/src-tauri/Cargo.toml
  • neon_echo/src-tauri/tauri.conf.json

The build injects the version at compile time and the app displays it in the top-right chip of the header.
