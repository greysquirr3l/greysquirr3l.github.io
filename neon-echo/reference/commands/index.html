Tauri commands

The backend exposes eleven commands. All of them are declared in src-tauri/src/lib.rs and registered in a single generate_handler! call.

Commands marked async run through off_main — they are dispatched to Tauri’s blocking thread pool so the window event loop keeps running.

version

Section titled “version”

Returns build metadata. Synchronous — there is no work to do.

The version comes from sparklepony::version, which injects the values at compile time via build.rs.

system_info

Section titled “system_info”

Live machine stats for the header chip. Async.

preview_input

Section titled “preview_input”

Pre-flight scan of the input tree. Async.

Argument Type
path String File or directory to scan

part_count is how many pieces a split archive resolved into. kind identifies the input form — a PST, a ZIP, or a multi-part archive.

This does not open a single mailbox. It walks the tree and counts.

extract

Section titled “extract”

The full extraction pipeline. Async.

Argument Type
app AppHandle<R> Injected by Tauri, used to emit progress
req ExtractRequest See below

Every field of ExtractRequest is optional except input:

Omitted fields fall back to the library defaults. The output path is resolved through config::safe_output_path so a macOS .app bundle — whose working directory is read-only — cannot end up writing into the app bundle.

cleanup_validate_emails

Section titled “cleanup_validate_emails”

RFC 5321/5322 syntax validation. Async.

Argument Type
input String CSV to read
output_valid Option<String> Where to write the passing rows
output_invalid Option<String> Where to write the failing rows

Defaults to contacts_valid.csv and contacts_invalid.csv in the user directory.

cleanup_validate_mx

Section titled “cleanup_validate_mx”

DNS-over-HTTPS MX domain validation. Async.

Argument Type
input String CSV to read
output_valid Option<String> Rows with a mail-receiving domain
output_invalid Option<String> Rows with a dead domain
no_throttle Option<bool> Skip rate limiting

The app uses fixed values for the remaining knobs: timeout: 8, concurrency: 6, delay_ms: 10, retries: 2.

cleanup_exclude

Section titled “cleanup_exclude”

Blacklist exclusion split. Async.

Argument Type
input String CSV to read
output_kept Option<String> Rows that pass the rules
output_excluded Option<String> Rows removed by the rules
blacklist Option<String> Blacklist file to apply
include_ambiguous Option<bool> Also exclude shared mailboxes

load_blacklist

Section titled “load_blacklist”

Load the blacklist configuration. Async.

Argument Type
path Option<String> File to read; omit for the resolved default

save_blacklist

Section titled “save_blacklist”

Write the blacklist configuration. Async.

Argument Type
path String File to write
config BlacklistConfig The rules to write

Parent directories are created first, so saving to a path that does not exist yet works.

default_blacklist

Section titled “default_blacklist”

The bundled default rules. Synchronous.

Used to reset the editor in the blacklist manager.

default_paths

Section titled “default_paths”

The platform-safe default paths. Synchronous.

Events

Section titled “Events”

The app emits exactly one event.

Event Payload
extract://progress ProgressUpdate Progress ticks during an extraction

The frontend subscribes with listen() and unsubscribes in onCleanup. An emit failure is logged to stderr and the run continues — a lost progress tick is not a reason to abandon an extraction.
