Neon Echo

One gesture — pick your PSTs — and one click. Contacts stream into a CSV as each mailbox finishes. PSTs, ZIP files containing PSTs, multi-part split PSTs, or any mix, are all accepted.

What you get

Section titled “What you get”

Pick, don't type

Open a folder of zipped PSTs, select individual PST or ZIP files, or drop them onto the window. Everything goes through native Tauri APIs, so you get real filesystem paths — not browser sandbox approximations.

Review before you extract

A pre-flight scan counts the mailboxes and total bytes before a single contact is read. You see the size of the job before you commit to it.

Contacts stream, not batch

The CSV is written incrementally as each mailbox finishes. The progress bar shows per-mailbox state, and the window stays responsive throughout.

The same engine underneath

Neon Echo links the sparklepony Rust library directly. It never shells out to the CLI binary — the extraction logic you use from the terminal is the extraction logic the app runs, in-process.

Cleanup built in

Validate email syntax, check MX records over DNS-over-HTTPS, and split against your blacklist — all from the advanced drawer, no terminal required.
