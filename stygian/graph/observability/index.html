Observability

stygian-graph exposes structured metrics and distributed tracing out of the box. Both are opt-in: neither requires code changes to your adapters or domain logic.

Metric name Type Labels Description
stygian_requests_total counter service, status Total requests per adapter
stygian_request_duration_seconds histogram service Request latency distribution

stygian_cache_hits_total counter cache Cache hits
stygian_cache_misses_total counter cache Cache misses

Structured tracing

Section titled “Structured tracing”

stygian-graph instruments all hot paths with the tracing crate. Any compatible subscriber (JSON, OTLP, Jaeger) receives full span trees.

Basic JSON logging

Section titled “Basic JSON logging”

Set RUST_LOG=stygian_graph=trace at runtime for full span output.
